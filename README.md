# 🍕 Zomato India Food App - Power BI Dashboard

## 📌 Project Overview
This dashboard analyzes Zomato's restaurant data across 
major areas of India, providing insights on ratings, 
costs, cuisine types, and online ordering trends.

## 📊 Key Insights
- ⭐ Average Rating: 3.51 out of 5
- 💰 Average Cost (2 people): ₹538
- 🏪 Total Restaurants: 7,105
- 👥 Total Ratings: 7.105K

## 📈 Dashboard Features
- Area-wise visitor count analysis
- Restaurant type distribution
- Online vs Offline order comparison
- Cuisine-wise rating breakdown
- Cost analysis by restaurant type

## 🛠️ Tools Used
- Power BI Desktop
- Microsoft Excel / CSV (Data Source)
- DAX (Data Analysis Expressions)
